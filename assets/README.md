# Assets Plan

This folder is reserved for safe portfolio assets such as sanitized logos, exported diagrams, or presentation images.

## Allowed Assets

- Sanitized Ava AI logo or wordmark.
- Exported Mermaid diagrams with generic labels.
- Demo-only screenshots.
- Presentation-safe architecture graphics.

## Disallowed Assets

- `.env` files, API keys, or access tokens.
- Uploaded HR policy documents.
- Database dumps, backups, or filestore content.
- Real employee data, payroll data, leave balances, expense records, or chat logs.
- Raw source code copied from the implementation repositories.

## Asset Naming

Use descriptive lowercase filenames:

```text
ava-ai-logo.png
architecture-overview.png
rag-workflow.png
portfolio-cover.png
```
