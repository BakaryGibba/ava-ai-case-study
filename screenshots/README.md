# Screenshots Plan

Screenshots should be captured with sanitized demo data only. Do not include real employee names, emails, payroll amounts, leave balances, uploaded HR policies, access tokens, request logs, or organization identifiers.

## Capture List

| Status | File | What It Captures | Why It Is Important |
| --- | --- | --- | --- |
| Captured | `landing.png` | First branded Ava AI screen | Establishes product identity and polish |
| Captured | `employee-chat-empty.png` | Empty employee chat with suggested prompts | Shows onboarding and prompt guidance |
| Captured | `employee-chat-answer.png` | Employee asks a policy question and receives an answer | Demonstrates core AI value |
| Captured | `employee-chat-handover.png` | Handover offer or open HR handover state | Shows human-in-the-loop safety |
| Captured | `admin-dashboard.png` | HR admin dashboard with metrics and charts | Shows operational value for HR teams |
| Captured | `admin-conversations.png` | Conversations table plus message drawer | Shows review and oversight workflow |
| Captured | `admin-escalations.png` | Escalation queue or handover sessions | Shows unresolved cases becoming HR workflow |
| Captured | `admin-documents.png` | Document upload/list/indexing view | Shows knowledge-base management |
| Pending | `admin-employees.png` | Employee directory | Shows local/HRIS employee visibility |
| Captured | `super-organizations.png` | Organization management and credit state | Shows multi-tenant governance |
| Captured | `super-api-usage.png` | API requests, token usage, costs, or trend dashboard | Shows AI cost governance |
| Captured | `super-settings.png` | AI provider/model/platform settings | Shows configurable AI operations |
| Pending | `super-logs.png` | Request or activity logs | Shows auditability |

## Recommended Style

- Use a browser width around 1440px for desktop captures.
- Capture mobile variants only if showcasing responsive design.
- Prefer clean demo records over blurred private data.
- Keep screenshots visually consistent: same theme, same browser zoom, same demo tenant.
